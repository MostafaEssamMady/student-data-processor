# 🎓 Student Data Processor

A simple and efficient Python program designed to process student information and manage grade scoring automatically.

## 🚀 Features
* **Name Formatting:** Cleans up user input by removing extra spaces and capitalizing names properly.
* **Score Processing:** Accepts new student scores and updates the data dynamically.
* **Statistical Analysis:** Automatically calculates total scores and average performance.

## 🛠️ Tech Stack
* **Language:** Python 3.x

   ```bash
